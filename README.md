# Clinical Trial Disease Category Classification

## Project Overview

This project applies Natural Language Processing (NLP) and Machine Learning techniques to classify clinical trial summaries into disease categories. The system processes textual clinical trial data, extracts meaningful features using TF-IDF vectorization, and predicts disease categories using a Random Forest Classifier.

The project also includes a Streamlit application that allows users to enter clinical trial summaries and receive disease category predictions in real time.

---

## Problem Statement

Clinical trial datasets contain large amounts of unstructured textual information. Manually identifying and categorizing disease-related studies can be time-consuming and inefficient.

This project automates the classification process by predicting disease categories directly from clinical trial summaries using NLP and Machine Learning.

## NLP Preprocessing

The following preprocessing techniques were applied:

* Lowercase Conversion
* Special Character Removal
* Stopword Removal
* Lemmatization
* Text Cleaning

---

## Feature Engineering

TF-IDF (Term Frequency-Inverse Document Frequency) Vectorization was used to convert textual clinical trial summaries into numerical features suitable for machine learning models.

---

## Machine Learning Models

| Model               | Accuracy |
| ------------------- | -------- |
| Logistic Regression | 84.19%   |
| Naive Bayes         | 77.81%   |
| Random Forest       | 84.37%   |

### Best Model

Random Forest Classifier achieved the highest accuracy and was selected as the final model.
